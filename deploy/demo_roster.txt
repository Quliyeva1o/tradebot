# WHY THIS FILE EXISTS: a .bat exists for every strategy/symbol pair, so
# install_tasks.ps1 registers eighteen tasks. Enabling all of them puts TWO
# Demo bots on GER40, JP225 and XAUUSD, and two bots on one symbol do not
# co-operate -- _partition_positions() sees the other's position as foreign and
# blocks entry, so whichever polls first wins and the other logs
# foreign_position_blocks_entry forever. That happened on XAUUSD on 2026-09-08
# (37 blocked entries in the log) and again on the VPS build on 2026-09-10.
#
# The allocation was a real decision, made per symbol on the numbers, but it
# lived only in Task Scheduler's enabled/disabled state -- nowhere in the repo.
# Rebuild from scratch and it was silently lost. Now it is version-controlled.
#
# Anything NOT listed here is disabled by install_tasks.ps1. Paper tasks are
# unaffected: they use per-strategy state files, never collide, and running
# both sides on a symbol is how the losing config stays measurable.
